# C6 Submission Requirements — International Economics

Access date: 2026-08-30.

Primary source: Elsevier / ScienceDirect Guide for Authors: https://www.sciencedirect.com/journal/international-economics/publish/guide-for-authors
Submission app landing page: https://submit.elsevier.com/INTECO

## Verified current requirements

- Journal scope includes trade and trade policy.
- The journal describes an additional submission form as `Short communication`, while the length policy calls the section `Short paper`.
- Short paper maximum: 7,000 words.
- Each exhibit reduces the word ceiling by 200 words; maximum five exhibits.
- Main text must be self-contained; editors/referees must be able to assess the contribution without appendices.
- Review is single anonymized, normally with at least two reviewers if sent out.
- Editable source files are required; `.tex` is accepted. PDF is not an acceptable source file by itself.
- Title-page information must include title, author names, full affiliation address(es), and a designated corresponding author with current contact information.
- Abstract maximum: 250 words.
- Keywords: 1–6 in English.
- Highlights are encouraged, submitted separately, 3–5 bullets, maximum 85 characters per bullet including spaces.
- No JEL-code requirement is stated in the current Guide for Authors.
- Competing interests: Elsevier's declarations tool should always be completed; if there is nothing to declare, the author selects `I have nothing to declare`. The resulting `.doc/.docx` file is uploaded with the submission.
- Funding sources must be disclosed. If there was no specific grant, the Guide recommends: `This research did not receive any specific grant from funding agencies in the public, commercial, or not-for-profit sectors.`
- Generative AI used in manuscript preparation must be declared in a section immediately before the references titled `Declaration of generative AI and AI-assisted technologies in the manuscript preparation process`.
- AI tools may not be listed as authors.
- CRediT roles are the journal's author-contribution framework; not all roles apply to every manuscript.
- Research-data policy is Option B. Software, code and models count as research data/materials; deposit/linking is encouraged, or an availability explanation should be given.
- Supplementary files must be submitted with the manuscript, cited/described, and are published essentially as received.
- Submission checklist asks for corresponding-author email, full postal address and phone number.
- A graphical abstract is encouraged but not required. No graphical abstract is planned for this note.
- No submission fee is stated in the current Guide for Authors.
- Open-access publication, if selected, may incur an APC; the current Guide does not provide a journal-specific amount on the page audited here.

## Live portal items not independently observable

The submission application requires JavaScript and did not expose article-type choices or fee fields to the audit environment. Therefore the following must be confirmed manually when the author opens the live portal:

1. exact article-type label (`Short communication` versus `Short paper`);
2. whether any submission fee is presented at the portal stage;
3. whether suggested reviewers are requested or required;
4. exact portal-only declaration fields;
5. open-access versus subscription choice and any current APC shown if OA is selected.
