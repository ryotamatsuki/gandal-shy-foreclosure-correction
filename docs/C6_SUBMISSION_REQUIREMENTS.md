# C6.1 Submission Requirements — International Economics

Access date: 2026-08-30.

Primary journal source: Elsevier / ScienceDirect Guide for Authors: https://www.sciencedirect.com/journal/international-economics/publish/guide-for-authors
Submission app: https://submit.elsevier.com/INTECO
Elsevier generative-AI policy: https://www.elsevier.com/about/policies-and-standards/generative-ai-policies-for-journals
Elsevier LaTeX instructions: https://www.elsevier.com/en-gb/researcher/author/policies-and-guidelines/latex-instructions

## Verified current requirements

- Journal scope includes trade and trade policy.
- The journal describes an additional submission form as `Short communication`, while the length policy calls the section `Short paper`; the exact live portal label must be confirmed.
- Short paper maximum: 7,000 words.
- Each exhibit reduces the word ceiling by 200 words; maximum five exhibits.
- Main text must be self-contained; editors/referees must be able to assess the contribution without appendices.
- Review is single anonymized, normally with at least two reviewers if sent out.
- Editable source files are required; `.tex` is accepted. PDF is not an acceptable source file by itself.
- Title-page information must include title, author names, full affiliation address(es), and a designated corresponding author with current contact information.
- Abstract maximum: 250 words.
- Keywords: 1–6 in English.
- Highlights are encouraged, submitted separately, 3–5 bullets, maximum 85 characters per bullet including spaces.
- No JEL-code requirement is stated in the current Guide for Authors.
- Competing interests: Elsevier's declarations tool should be completed; if there is nothing to declare, use the equivalent no-competing-interest option and upload any generated declaration file required by the portal.
- Funding sources must be disclosed. If there was no specific grant, the Guide recommends: `This research did not receive any specific grant from funding agencies in the public, commercial, or not-for-profit sectors.`
- Generative AI used in manuscript preparation must be disclosed in a separate declaration immediately before the references; the disclosure should identify the tool, purpose, human review/editing, and author responsibility.
- AI tools may not be listed as authors.
- If generative AI is used in research methods, including code development or data analysis, that use must be described as part of the methodology. AI-assisted research code remains subject to the same validity and reproducibility standards as other code.
- CRediT roles are the journal's author-contribution framework; AI tools receive no CRediT role.
- Research-data policy is Option B. Software, code and models count as research data/materials; deposit/linking is encouraged, or an availability explanation should be given.
- Supplementary files must be submitted with the manuscript, cited/described, and are published essentially as received.
- Submission checklist asks for corresponding-author email, full postal address and phone number.
- A graphical abstract is encouraged but not required. No graphical abstract is planned for this note.
- No submission fee is stated in the current Guide for Authors.
- Open-access publication, if selected, may incur an APC; the exact current amount should be checked in the live portal/journal pricing page.

## Elsevier LaTeX processing rule

Editorial Manager cannot process LaTeX submissions containing subfolders. All TeX, bibliography, style, figure and related source files must be stored at the same folder level. The development repository may remain modular, but the submission export must be flattened before upload.

## Live portal items not independently observable

1. exact article-type label (`Short communication` versus `Short paper`);
2. whether any submission fee is presented at the portal stage;
3. whether suggested reviewers are requested or required;
4. exact portal-only declaration fields;
5. open-access versus subscription choice and any current APC shown if OA is selected;
6. whether the full private postal address and phone are required in the uploaded title-page file in addition to portal fields.
