The old PASS therefore certified a candidate, not an equilibrium-set characterization.

## 4. Revised numerical architecture

The new `code/verify_numerical.py` works directly from the primitive Salop geometry.

### 4.1 Geometry and demand

The circle has circumference `3` and firms are located at `0`, `1`, and `2`. Consumer points are discretized at cell midpoints. Delivered price is posted price plus squared shortest-arc distance.

For each profile `(p_1,p_2,p_3)`, demand is computed from the lower delivered-price envelope.

### 4.2 Global unilateral best response

For each consumer point and deviating firm `i`, the code calculates the highest posted price at which `i` weakly beats the lower delivered-price envelope of the other two firms. Sorting these thresholds enumerates every discrete demand plateau.

Thus the best-response routine searches the full one-dimensional deviation price space represented by the discretized market, rather than a local neighborhood or a preselected grid of deviation prices.

### 4.3 Two strategy modes

The code has two explicit modes.

- **Unrestricted mode:** no lower price floor is imposed.
- **Cost-floor mode:** deviations and candidate profiles must satisfy `p_i >= mc_i`, so the outsider must satisfy `p_3>=c`.

The Astra equilibrium `(3/2,3/2,5/2)` at `c=4` is admissible in unrestricted mode and deliberately inadmissible in cost-floor mode.

## 5. Valid equilibrium-family falsification

The high-resolution audit uses `N=80,000` consumer cells and a conservative fixed discretization allowance of `0.0009` in profit.

The code tests 91 profiles drawn from the C0–C1R equilibrium families.

### 5.1 Unrestricted U1 family

Multiple values of `c` are combined with multiple member prices `s`, using

`(p_1,p_2,p_3)=(s,s,s+1)`

for `3/2<=s<2` and `c>=s+1`.

This explicitly varies `p_3` independently of `c`; the test is no longer confined to `p_3=c`.

### 5.2 Unrestricted U2 family

For `s=2`, the code tests multiple outsider prices `r>=3`, including values below, equal to, and above `c` where admissible under the unrestricted game.

### 5.3 Cost-floor F1/F2 families

For `5/2<c<3`, the code tests `(c-1,c-1,c)`.

For `c>=3`, it tests `(2,2,r)` for multiple `r>=c`.

### Numerical result

Across all 91 valid-family profiles,

`max apparent equilibrium gain = 5.6249531e-05`,

which is below the pre-specified discretization allowance

`0.0009`.

No profile in the exact stated theorem class generated a material profitable unilateral deviation.
